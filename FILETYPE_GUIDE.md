# File Type Search Guide

## Overview

The Media Search Engine helps you find royalty-free media based on file types, formats, and technical specifications.

## File Type Categories

### 📷 Photos (JPG, PNG, WebP)
High-quality photographic images suitable for:
- Website backgrounds and hero images
- Blog posts and articles
- Social media content
- Print materials and marketing
- Professional presentations

**Supported Formats:**
- **JPG/JPEG** - Standard compressed format, best for photographs
- **PNG** - Lossless format with transparency support
- **WebP** - Modern format with superior compression

**Typical Resolutions:**
- Full HD: 1920x1080 pixels
- 2K: 2560x1440 pixels
- 4K: 3840x2160 pixels
- 5K+: 5120x2880+ pixels

### 🎨 Vectors (SVG, AI, EPS)
Scalable graphics that maintain quality at any size:
- Logos and branding elements
- Icons and UI elements
- Infographics and diagrams
- Print designs
- Web graphics

**Advantages:**
- Infinite scalability without quality loss
- Small file sizes
- Easy to edit and customize
- Perfect for responsive design

### 🖼️ Illustrations
Artistic drawings and digital artwork:
- Editorial illustrations
- Character designs
- Concept art
- Decorative elements
- Educational materials

### 🎬 Videos (MP4, MOV, WebM)
Motion content for dynamic presentations:
- Website backgrounds
- Social media posts
- Presentations and demos
- Advertising campaigns
- Content creation

**Common Resolutions:**
- HD: 1280x720 pixels
- Full HD: 1920x1080 pixels
- 2K: 2560x1440 pixels
- 4K: 3840x2160 pixels

## Search Strategies

### By Use Case

**Website Design**
1. Select "Photos" media type
2. Choose "Landscape" orientation
3. Set minimum resolution to Full HD
4. Filter by relevant colors

**Social Media Content**
1. Select "Photos" or mixed media
2. Choose "Square" or "Portrait" orientation
3. Use color filters to match brand
4. Enable high-quality filters

**Print Materials**
1. Select high-resolution photos
2. Set minimum resolution to 4K
3. Consider vector formats for scalability
4. Check licensing for commercial use

**Video Projects**
1. Select "Videos" media type
2. Choose appropriate orientation
3. Set minimum resolution based on output
4. Check duration in results

## Resolution Guidelines

### Web Use
- **Thumbnails:** 400x300 pixels
- **Blog Images:** 1200x800 pixels
- **Hero Images:** 1920x1080 pixels
- **Retina Displays:** 2x resolution

### Print Use
- **Business Cards:** 300 DPI minimum
- **Flyers:** 300 DPI at final size
- **Posters:** 150-300 DPI
- **Billboards:** Vector formats recommended

### Social Media
- **Instagram Post:** 1080x1080 pixels (square)
- **Instagram Story:** 1080x1920 pixels (portrait)
- **Facebook Cover:** 820x312 pixels (landscape)
- **Twitter Header:** 1500x500 pixels (landscape)
