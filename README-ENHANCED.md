# 📁 File Type Media Search Engine

A powerful, file type-focused media search engine for finding royalty-free images and videos from multiple sources. Search by file format, resolution, orientation, and technical specifications.

## 🌟 Key Features

### 📂 File Type Focused Search
- **Dedicated File Type Filters:** Photos, Vectors, Illustrations, Videos, Animations
- **Format Specifications:** JPG, PNG, WebP, SVG, MP4, MOV, WebM, GIF
- **Visual File Type Indicators:** Clear badges showing format and specifications
- **Format-Specific Search:** Target exact file types for your needs

### 🎯 Advanced Filtering System
- **Resolution Filters:** Full HD, 2K, 4K, and custom resolutions
- **Orientation Filters:** Landscape, Portrait, Square
- **Color Filters:** Search by dominant color
- **Quality Filters:** High-quality only, editorial use, exclude people
- **Multi-Source Search:** Unsplash, Pexels, Pixabay

### 🎨 Modern User Interface
- **File Type Cards:** Interactive cards with format information
- **Dual View Modes:** Grid and List views
- **Detailed Media Cards:** Resolution, file type, and statistics
- **Modal Preview:** Full details before download
- **Responsive Design:** Works on all devices

## 🚀 Quick Start

### Installation

1. Clone the repository
2. Open `index-enhanced.html` in a text editor
3. Add your API keys to the `API_KEYS` object
4. Open `index-enhanced.html` in your browser

### Getting API Keys

See [API_SETUP.md](API_SETUP.md) for detailed instructions on obtaining free API keys from:
- Unsplash (Photos)
- Pexels (Photos & Videos)
- Pixabay (Photos, Videos, Vectors)

## 📖 Usage

1. **Select File Type:** Click on a file type card (Photos, Vectors, Videos, etc.)
2. **Enter Search Terms:** Type keywords in the search box
3. **Apply Filters:** Choose orientation, resolution, color, and quality options
4. **Search & Browse:** View results in grid or list view
5. **Download:** Click on any item for details and download options
