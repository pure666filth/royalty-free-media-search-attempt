# 📁 File Type Search Engine

A multi-source file search interface with support for torrent trackers, Usenet indexers, FTP search, direct download sites, and specialized resources.

## ⚠️ Important Notice

**This is a demonstration interface only.** This tool does not host, store, or distribute any files. It shows how a multi-source file search interface could work.

- **Source Selection** - Choose which sources to search with checkboxes
- **File Type Filtering** - Filter by specific file categories
- **Quality Options** - 4K, 1080p, 720p, 480p
- **Sort Options** - Relevance, Date, Size, Seeders
- **Size Filters** - Min/Max file size
- **Year Filter** - Search by year

## 🚀 Usage

1. **Select File Type** - Click on a category (Movies, Audio, etc.)
2. **Choose Sources** - Check the sources you want to search
3. **Enter Query** - Type your search keywords
4. **Set Filters** - Choose quality, size, year options
5. **Search** - Click "Search Files" button
6. **View Results** - Browse results from all selected sources

## 📋 Source Categories

### Torrent Trackers
Public torrent sites with large databases of files. Best for movies, TV shows, software, and games.

### Usenet Indexers
Usenet search engines for binary newsgroups. Requires Usenet provider subscription.

### FTP Search
Search engines for open FTP servers and directories. Good for finding direct downloads.

### Direct Download
Search engines for file hosting services like Mega, Rapidgator, etc.

### Specialized Sites
Focused on specific content types:
- AudioBook Bay - Audiobooks
- Library Genesis - Books and academic papers
- Sci-Hub - Scientific papers
- RuTracker - Russian tracker with diverse content

### Web Crawlers
Search open directories and web servers for publicly accessible files.
