# 📁 File Type Search Engine

A modern search interface for finding movies, videos, audio, audiobooks, software, documents, and games by file type.

## ⚠️ Important Notice

**This is a demonstration interface only.** This tool does not host, store, or distribute any files. It's designed to show how a file search interface could work.

## 🎯 File Type Categories

### 🎬 Movies (MP4, MKV, AVI)
### 📹 Videos (MP4, WebM, MOV)
### 🎵 Audio (MP3, FLAC, WAV, AAC)
### 📚 Audiobooks (M4B, MP3)
### 💿 Software (EXE, ISO, DMG)
### 📄 Documents (PDF, EPUB, MOBI)
### 🎮 Games (ISO, EXE)

## 🔍 Features

- File type filtering by category
- Quality options (4K, 1080p, 720p)
- Sort by relevance, date, or size
- Modern dark theme interface
- Responsive design

## 🚀 Usage

1. Select a file type category
2. Enter search keywords
3. Choose quality and sort options
4. Click "Search Files"
